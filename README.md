# AI Student OS

AI Student OS is a full-stack web application built to simplify the way students plan, organize, and manage their studies. The project combines task management with AI-powered planning to create a single workspace where students can schedule their learning, monitor their progress, and stay consistent throughout an academic term.

The long-term vision is to build an AI learning companion that not only helps students organize their work but also guides them through the entire learning process—from planning and revision to assessments and performance analysis.

## Features

Current version includes:

- User authentication
- Task management
- AI-generated study plans
- XP and streak system
- Progress dashboard

The next version will introduce:

- Email reminders for approaching deadlines
- AI planner with image and text-based syllabus input
- Daily AI-generated quizzes
- Full-length mock examinations
- Context-aware AI chat assistant
- Learning analytics and performance insights

## Getting Started

Clone the repository

```bash
git clone https://github.com/your-username/ai-student-os.git
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

## Roadmap

This project is being developed in multiple phases.

Version 1 focuses on the core productivity system, including authentication, task management, and AI study planning.

Version 2 expands the platform with adaptive learning features such as reminders, AI-generated quizzes, mock examinations, and a personalized AI assistant.

Future versions will focus on collaboration, advanced analytics, and additional learning tools.
